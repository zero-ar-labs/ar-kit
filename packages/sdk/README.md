# `@zero-ar/sdk`

The default TypeScript entry point for applications that start, attach to and
control Zero-AR work. It provides durable run handles, authoring builders and
sequential or research orchestration helpers over the public client.

The SDK holds no runtime state and contains no model loop or storage engine.
It connects to a running Zero-AR endpoint. See the
[package guide](../../docs/npm-packages.md) and
[v0.1.0 usage guide](../../docs/using-zero-ar-v0.1.0.md).
