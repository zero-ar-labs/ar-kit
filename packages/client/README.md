# `@zero-ar/client`

The generated typed client for the native Zero-AR HTTP and event API. Use it
for route-level control, durable event cursors, artifact transfer, run export
and import, or administrative operations.

The package also exports the OpenAPI 3.1 contract at
`@zero-ar/client/openapi`. It contains no runtime server and connects only to
a configured endpoint. See the [package guide](../../docs/npm-packages.md).
