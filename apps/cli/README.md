# `@zero-ar/cli`

The `zeroar` command for starting, observing, controlling, recovering,
exporting and administering Zero-AR work through the public API.

The npm package is a client and does not contain the runtime server. Select a
hosted or Full Cell endpoint with `--url` or `ZERO_AR_URL`, or install the
separate Local Lite distribution when you want a bundled local endpoint. See
the [package guide](../../docs/npm-packages.md) and
[v0.1.0 usage guide](../../docs/using-zero-ar-v0.1.0.md).
